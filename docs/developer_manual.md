## Developer Manual

Welcome to the CityBikes App developer documentation. This section provides all the 
necessary information to set up, run, test, and maintain the application on your local machine.

To set up the application locally, ensure you have Node.js and npm installed.

1. Clone the repository to your local machine:
   git clone git@github.com:KimMai03/CityBikes-App.git

2. Navigate into the project directory: cd CityBikes-App

3. Install npm and nodemon

4. Running the App on Your Server: 
    Run npm start in your terminal
    The server will be available at http://localhost:3000
