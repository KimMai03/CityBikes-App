# Project Title: CityBikes App

## Description: 
CityBikes App is a Node.js/Express web application that proxies 
data from the public from CityBikes API (https://citybik.es/) to 
provide a real-time status of bike station around the world. 
Users can use this app to search  by city or country for specific 
bike location, and look up for live status, for example, is there 
any available bikes at a specific station, station location, 
station general information, and and submit support requests 
through a contact form. Contact submissions are persisted in a 
Supabase (PostgreSQL) database.
Whether you are commuting in your hometown or exploring a new city, 
this app helps you find the nearest available ride with ease.

## Target browsers: 
This app will target users from Android platforms, including Google Chrome, Firefox, or Microsoft Edge
